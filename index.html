Before You Flash

  • Unlock your bootloader.
  • Backup all your data.
  • Ensure battery is above 60%.
  • Verify file checksums (SHA256).
  • Disclaimer: I am not responsible for bricked devices. Proceed at your own risk.

FAQ

How do I open MEGA links?
Click the "Download (MEGA)" button. It opens in a new tab. For large files, MEGA may prompt you to use their desktop app for better performance.
How do I flash a ROM zip?
Boot into custom recovery (TWRP/OrangeFox) → Wipe data/cache/dalvik → Install → Select ROM zip → Swipe to flash → Reboot.
How do I flash a kernel?
Same as ROM: boot to recovery → Install → Select kernel zip → Swipe to flash → Reboot. Some kernels need specific ROM compatibility.
How do I flash stock firmware (fastboot)?
Boot to fastboot mode (Power + Volume Down) → Connect via USB → Run flash script or flash partitions manually with fastboot flash .
What if my device won't boot?
Try booting to recovery (Power + Volume Up) and restore a backup, or re-flash stock firmware via fastboot/EDL mode.
