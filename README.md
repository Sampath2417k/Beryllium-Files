# Beryllium-Files
Static POCO F1 (beryllium) file hub. No build step, no external requests.

- Edit **data.js only** to add files or guides (format is explained at its top).
- Files: index.html, style.css, app.js, data.js.
- Test: `python -m http.server 8000` then open http://localhost:8000
- Deploy: push to `main` (GitHub Pages, root).
